## 3. §14 UStG — Pflichtangaben auf Rechnungen

Для вычета Vorsteuer (входящего НДС) входящий инвойс должен содержать все обязательные реквизиты:

### Полный инвойс (> €250 брутто)

1. Vollständiger Name und Anschrift des leistenden Unternehmers (поставщик)
2. Vollständiger Name und Anschrift des Leistungsempfängers (получатель)
3. Steuernummer **или** USt-IdNr. поставщика
4. Ausstellungsdatum (дата выставления)
5. Fortlaufende Rechnungsnummer (последовательный номер)
6. Menge und Art der gelieferten Gegenstände / Art und Umfang der Leistung (описание)
7. Zeitpunkt der Lieferung / Leistungserbringung (если отличается от даты инвойса)
8. Entgelt (нетто-сумма) по каждой ставке НДС отдельно
9. Anzuwendender Steuersatz (ставка НДС)
10. Auf das Entgelt entfallende Steuerbetrag (сумма НДС)

**Отсутствие любого пункта → Vorsteuer по этому инвойсу нельзя вычесть.**

### Kleinbetragsrechnung (≤ €250 брутто) — §33 UStDV

Достаточно: дата, поставщик (имя), описание, сумма брутто, ставка НДС. Номер счёта и адрес получателя не обязательны.

### Kleinunternehmer — обязательная фраза на исходящих инвойсах

```
Gemäß §19 UStG wird keine Umsatzsteuer berechnet.
```

### Reverse Charge (§13b UStG) — обязательная фраза

```
Steuerschuldnerschaft des Leistungsempfängers gemäß §13b UStG.
```

## 4. Ключевые правила НДС

### Kleinunternehmerregelung §19 UStG

- **Нет НДС** на исходящих инвойсах → обязательная фраза (см. выше)
- **Нет вычета Vorsteuer** с входящих инвойсов
- **Нет UStVA** (кроме случая: innergemeinschaftliche Erwerbe > €12 500/год → тогда UStVA обязателен)
- **Нет ZM** (Zusammenfassende Meldung)
- Порог 2025: ≤ €25 000 оборота предыдущего года **и** прогноз текущего ≤ €100 000

### Reverse Charge §13b UStG — когда применяется

Применяется к **входящим** услугам (не товарам!) от поставщиков из других **стран ЕС**, если покупатель является Unternehmer (предпринимателем):
- SaaS-сервисы: Adobe, GitHub, Figma, Slack, ChatGPT/OpenAI (IE), Canva (AU — НЕ EU, другие правила)
- Freelance-услуги от EU-фрилансеров
- IT-консалтинг от EU-компаний

**Механизм:** поставщик выставляет инвойс без НДС (0%), покупатель сам исчисляет НДС по немецкой ставке и одновременно декларирует его как Umsatzsteuer (строка 46/52 UStVA) и как Vorsteuer (строка 67 UStVA). Итог: нулевой платёж при наличии полного права на вычет.

**НЕ применяется:**
- Поставщики из третьих стран (US, UK, CH, CN) → другие правила §3a UStG
- Товары из EU → ZM, но не Reverse Charge в этом смысле
- Kleinunternehmer: нет права на Vorsteuer, но обязан декларировать EU-Erwerb отдельно

### НДС на услуги фотографа — частый кейс

**Услуги фотографа (Werklohn, Ablichtung):** 19%  
**Künstlerische Werke (оригинальные произведения по §12 Abs. 2 Nr. 13c):** 7% — только для оригинальных уникальных произведений искусства, не для коммерческой съёмки

Частая ошибка: фотограф выставляет 7% на обычные коммерческие съёмки (Werbefotografie, Produktfotografie) → ERROR.

## 5. Ключевые правила EStG для Einzelunternehmer

### Betriebsausgaben §4 EStG — что вычитается

| Расход | Правило |
|---|---|
| Homeoffice Tagespauschale | €6/день × дни работы из дома, макс. €1 260 |
| Homeoffice eigenes Zimmer | Полные расходы пропорционально м², только если это Mittelpunkt der Tätigkeit |
| Bewirtungskosten | 70% нетто + 100% Vorsteuer (если плательщик НДС) |
| Geschenke an Geschäftspartner | Nur bis €50 netto pro Person pro Jahr §4 Abs. 5 Nr. 1 |
| Pkw Firmenwagen | 100% Betriebsausgaben минус ежемесячный Privatanteil (1%-Regel) |
| Pkw privat (Kilometerpauschale) | €0,30/km × km |
| Telefon/Internet (privat genutzt) | Üblicherweise 50–75% als Betriebsausgabe |
| Fortbildung (berufliche) | 100% |
| Fachliteratur | 100% |
| Berufsverbände | 100% |

### Bewirtungskosten §4 Abs. 5 Nr. 2 EStG — обязательная документация

Для признания расходов требуется Bewirtungsbeleg (квитанция ресторана) с:
1. Datum und Ort
2. Namen aller Teilnehmer
3. Anlass (конкретная деловая цель — не «Kundenpflege»)
4. Betrag (включая Trinkgeld)
5. Unterschrift des Bewirtenden

**Без этих данных расход не принимается вообще** (ни 70%, ни 0%).

### Privatentnahme / Privateinlage §4 Abs. 1 EStG

Разрешены только для Einzelunternehmer (Freiberufler, Gewerbetreibender). Для GmbH/UG/AG — другой механизм (Ausschüttung, Darlehen). Корректная категория — «Privatentnahme» / «Privateinlage», не «Gehalt».

**Как использовать в проверках:**

```

  → WARNING E-03: Bewirtungskosten выше отраслевого Richtsatz
```
